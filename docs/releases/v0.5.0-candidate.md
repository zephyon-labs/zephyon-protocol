# Proposed v0.5.0 release notes — unpublished candidate

Adds `RuntimePolicyEvaluatorV1`, a deterministic fail-closed admission primitive for the existing exact Economic Intent Envelope V1. It evaluates pinned policy configuration and qualified evidence at explicit authoritative time/context, produces bounded APPROVED/REJECTED decisions and verifies them back to the existing Runtime decision binding.

New capabilities:

- Validated immutable policy profiles with exact asset/atomic amount, network, purpose, destination and evidence constraints.
- Explicit trusted ingestion capability, opaque qualified evidence sets, whole-record authentication requirements and rejection of matching-ID impersonation.
- Versioned profile/evidence-set commitments and stable rejection/input error codes.
- One explicitly bounded TEST/DEVNET ONLY USDC profile. No production profile or provider/trust fabrication.
- Documentation marking legacy approving factories and optional-evidence aggregation as smoke/compatibility paths.

Compatibility: all v0.4 exports, envelope serialization/digests, execution behavior and dependency versions are retained. Additions are opt-in. Existing Backend/Site dependencies and behavior are unchanged. New adoption requires preparation to commit the selected profile digest before user consent; already confirmed envelopes cannot be rewritten to fit it.

This candidate is not published, tagged, pushed, deployed or activated. Independent Protocol audit is the next gate. A later authorized release and Backend/Site integration must provide real ingestion, current eligibility/revocation checks, durable decision identity and recovery. Both deployment holds remain in place.
